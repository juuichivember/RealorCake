# RealorCake
A repository of a cake decoration game called 'Namkhing's Cake'

เพื่อไม่ให้สับสน ไม่ต้อง merge/pust ขออัพโหลดแค่ไฟล์ที่มีการเปลี่ยนแปลง โดยให้อัยย์ก็อปแค่โค้ด main กับ element จาก branch นี้ได้เลย ส่วน folder Sound ให้เอาไปเก็บใน folder Element
(เค้าโหลด main มาแก้ใหม่กลัวไปทับงานเดิมตัวเอง+ ใช้ gitละสับสน)

ไฟล์ที่แก้ไขมีแค่  Element เพิ่ม Sound, Main, state ที่เหลือไม่ได้ยุ่ง
เมื่อกด button ที่มีเสียง เสียง click จะไม่ดังเพื่อไม่ให้ซ้ำซ้อน
เสียงตอนเลือกท็อปปิ้งบนชั้น pop จะดังเมื่อแสดงท็อปปิ้งเท่านั้น เปลี่ยนสีจะไม่ดัง แต่ปกติแล้วถ้า click เมื่อไหร่ก็จะมีเสียงอยู่แล้ว

Elements\Sound\ApplyFrosting.mp3  เสียงเมื่อแสดง behindcream, lowercream, middlecream, topcream, topping /
Elements\Sound\EndPage.mp3 เสียง background เมื่ออยู่ใน State endpage /
Elements\Sound\InGamePage.mp3  เสียง background เมื่ออยู่ใน State Decoration /
Elements\Sound\IntroPage.mp3 เสียง background  เมื่ออยู่ใน State start /
Elements\Sound\NormalClick.mp3 เมื่อมีการ click /
Elements\Sound\RandomPage.mp3 เสียง background เมื่ออยู่ใน State RandomCake /
Elements\Sound\ResetCake.mp3 เสียงเมื่อกดปุ่ม reset /
Elements\Sound\ShowScorePage[Lose].mp3 เมื่อ แพ้ background_lose ใน state score /
Elements\Sound\ShowScorePage[Win].mp3 เมื่อ ชนะ background_win ใน state score /
Elements\Sound\StartClick.mp3 เมื่อกดปุ่ม play_button /
