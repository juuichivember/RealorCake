# RealorCake
A repository of cake decoration game called 'Real or Cake?' (Temporary)
อัพเดต ReakOrCake เวอร์ชันนี้ แก้ไข not only 1080p
สิ่งที่เปลี่ยนแปลงคือมี 3 ไฟล์ real_or_cake, 720p ยืดหยุ่น, 720p ไม่ยืดหยุ่น และโฟลเดอร์ Element
real_or_cake.py = เปลี่ยนโครงสร้างโค้ดใหม่ จัดระเบียบ เป็นขนาด 1080p เต็ฒจอ ยืดหยุ่นไม่ได้ แต่สวยที่สุด
real_or_cake_720p_non-flexible.py = เอา 1080 มาแก้ ให้เหมาะกับ 720 ย่อ/ขยายไม่ได้ มีการเปลี่ยนภาพพื้นหลังสำหรับขนาดนี้เฉพาะ ถ้าใช้รูปเดิมตำแหน่งโต๊ะรองจะเบี้ยว เลยไปตัดต่อรูปเองให้โต๊ะพอวางได้ ส่วนผนังยังขนาดเดิม
real_or_cake_720p_flexible.py = แก้จาก 720non flex คือเป็นแบบย่อขยายได้ สัดส่วนโอเค ทั้ง 2 ตัว 720 มีปัญหาคือตัว thumbnail ที่วางอยู่บนชั้นมีขนาดใหญ่เมื่อวางแล้วจะโดนบีบอัดให้เล็กพอดีกับชั้น ทำให้รูปไม่ชัด ส่วนตัวคิดว่าโค้ดนี้อาจยังไม่ต้องใช้ในเวอร์ชันนี้ เพราะความซับซ้อนสูง ถ้าทำต่ออาจมีปัญหาในการปรับให้มันresizeเท่ากัน
